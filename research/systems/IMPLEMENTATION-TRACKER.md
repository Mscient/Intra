## Current position

- The Java 21 CLI compiles and supports normalized-bar validation and backtest replay for one dated futures contract or one option premium series at a time, including supplied session-boundary completeness checks and strict same-session interval spacing unless an explicit diagnostic override is set.
- The replay uses a long-only SMA harness, either next-eligible-bar-open fills or opt-in verified L1 full-size/whole-lot partial top-of-book IOC fills, explicit adverse tick slippage and fee inputs, an independent position/notional/session-loss risk gate, and local OMS/fill/trade/equity/session-reconciliation artifacts, published atomically after output hashes are written. Partial mode caps each fill at displayed top size rounded down to whole market lots, cancels the IOC remainder, and accounts for partial position basis, fees, and checkpoint recovery. Neither L1 mode models queue priority. The quote journal hash participates in run identity and independent reconciliation reselects quote references and verifies filled quantity. Position handling supports `ALLOW_OVERNIGHT`, fail-closed `REQUIRE_FLAT`, and an optional session-end exit under the selected execution model; that policy still requires review.
- Run-folder verification recomputes the recorded output hashes and checks the manifest ID; it does not re-open inputs or validate data rights.
- Effective-dated contract resolution, explicit session calendars, and hashed run manifests are required. Each open session resolves against a hashed effective-dated caller registry for date/scope/source, timezone, session window, and lot/tick consistency; the registry's source verification status remains an operator assertion. Expiry stitching, index-to-futures substitution, passive-touch fills, and live order egress are not supported.
- A clearly synthetic fixture was validated and replayed through the CLI: run `e9c5e0585cbf2dba6c24d632`, 30 bars, one complete supplied session, `REQUIRE_FLAT`, final position 0, `SYNTHETIC_PLUMBING_ONLY`, diagnostic net P&L `-1.36 INR`. No behavior tests or real-data strategy evaluation were performed; no real market data, credentials, account, or broker API were accessed.
- A separate Python offline backtest engine is described in earlier session records but its implementation was not present in the checked-out HFT 2 workspace; the Java simulator is not represented as a port of it.
- Added standalone caller-input European BSM and Black-76 APIs for theoretical value and delta/gamma/vega/theta/rho. They compile with the CLI but are not integrated into replay, settlement, or portfolio accounting and have not been independently validated against a second implementation or calibrated to a volatility surface. User-supplied synthetic benchmark source/JSON are archived under research/systems/option-pricing-benchmark and have not been executed or treated as independent expected values.
- Added a deterministic toy limit book with price/time matching, partial fills, cancellation, and market-IOC sweeps in integer ticks and units. Its exchange-neutral assumptions and limitations are documented separately; it is not integrated into strategy replay or calibrated against event data.
- Added a generic single-price call-auction clearing/allocation API with explicit unresolved handling when no equilibrium price is found. It has no session calendar or exchange-regime selection and remains outside historical replay pending rule-date evidence.
- Integrated verified L1 quote history into strategy replay through opt-in full-size and whole-lot partial top-of-book IOC models. Quote source, sequence, receive time, reference price, and model are persisted per fill; quote-side size consumption resumes from verified checkpoint fills. Passive queues, depth, aggregate capacity, and market impact remain open. See [L1 strategy execution](../../Intra-Paper-System/docs/L1-STRATEGY-EXECUTION.md).
- Added `feed-capture-reconcile` to verify raw and lifecycle journals independently and compare raw message receive times with acknowledged subscription windows using source/connection/subscription IDs and explicit wall-clock tolerance. It reports unmatched messages, empty acknowledged intervals, transition/timestamp anomalies, and both chain hashes. It does not map decoded instruments, establish completeness or data rights, or connect to a vendor feed.
- Added `raw-capture-clock-report` to compare captured wall-clock and monotonic elapsed-time deltas per source/connection using an explicit diagnostic tolerance. It reports wall regressions and clock divergence but does not verify UTC offset/accuracy, feed time, completeness, or order-path latency.
- Added a GitHub Actions Java 21 build-only workflow for pushes and pull requests to `main`, plus manual dispatch. It compiles and packages the CLI on Windows and retains the JAR artifact for 14 days. The first hosted run succeeded for `14f2e0771d8149dd0c36e4e55a3c2c4a3285f636` ([run 41628715122](https://github.com/Mscient/Intra/actions/runs/41628715122)); tests are not part of this workflow.

## Reusable backtesting research

- The current Wave A runner and S01–S03 specification concern NIFTY 50 index-candle signal markouts. Those markouts are not futures/options fills or executable P&L.
- Keep session-level chronological splits, provenance hashes, variant registration, eligibility rules, and a sealed holdout for future strategy research. Split validation, exact run-to-registration binding, and diagnostic session summaries by development/validation/holdout exist. Dependence-aware scoring, DSR/PBO, and sealed-holdout controls are not implemented; the partition report does not grant performance eligibility.
- A completed-bar signal may fill no earlier than the next eligible bar. A candle touching a passive limit does not establish a fill.
- Caller-input European option model values and Greeks are not observed option premiums or fills; until volatility/rate inputs and model assumptions are validated and replay integration is independently checked, use the premium-series replay for option diagnostics.
- Preserve dated futures/options contracts and master snapshots. Do not stitch expiries or map an index candle to a contract fill.
- Historical F&O coverage, local retention terms, exact dated costs/margins, and complete session-calendar evidence remain open. Synthetic runs are plumbing-only; other runs are diagnostic-only in this implementation.
