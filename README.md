# Nifty Intraday Research Project

This repository tracks research for a cost-aware Nifty intraday paper-trading system built around a retail broker API in India. The supplied brief sets the initial constraints: own account, Nifty first, Python research, no paid tick feed at the outset, and a 90-day paper-system target.

The research sequence starts with market microstructure, then options and volatility, execution, validation, and system operations. Research notes record what the available evidence supports and distinguish book coverage from independently sourced findings. They do not claim that any strategy is profitable or ready for live trading.

## Source and text policy

Use publisher pages, papers, authorized previews, library access, and public-domain or openly licensed works. Do not download or commit pirated scans or reproduce complete copyrighted books. Keep short quotations within fair-use limits; prefer original summaries with citations. If a complete book requires a subscription or library login, record that access status and continue with lawful public material until authorized access is available.
